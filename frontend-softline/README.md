# Тестовая витрина Softline

Витрина на React, TypeScript и Vite использует Go API из каталога `recsys`. Гость видит макет магазина. После входа открывается личный кабинет с выдачей для тестового профиля.

## Локальный запуск

Поднимите синтетическую PostgreSQL, сервис рекомендаций и HTTP API по [инструкции проекта](../README.md). Подготовьте четыре профиля по [сценарию демо](../recsys/docs/demo/README.md).

Из каталога фронтенда выполните:

```sh
npm ci
npm run dev
```

Откройте [витрину](http://localhost:5173/). Vite направляет `/api/v1` на `http://localhost:8080`. Другой адрес задаётся через `VITE_PROXY_RECSYS_TARGET`.

## Как проверить

- Гостевые рекомендации загружаются в раздел «Популярные товары». Нажмите «Войти» в меню магазина. Войдите как `notver`, `verb2b` или `verb2c` и проверьте статус рядом с логином.
- Запишите покупку из каталога и проверьте, как изменилась выдача профиля.
- Войдите как `admin` и откройте «Отладка рекомендаций». Выбор профиля показывает снимок, время ответа, причины, оценки, граф, счётчики базы и сохранённые прогоны.

Из каталога фронтенда `npm run build` проверяет сборку. `npm run test:e2e:demo` проверяет гостевой режим, вход и права администратора. [Параметры браузерного теста](../recsys/docs/demo/README.md)
