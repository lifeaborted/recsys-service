# Сквозные проверки

После подключения хранилища запустите отдельный экземпляр стенда на синтетических данных. Интегратор владеет запуском стенда, а участники добавляют проверки в `data/`, `recommend/`, `evidence/` и `demo/` соответственно. Первый сценарий проверяет вход одного тестового профиля, карточку с доказательством и изоляцию покупок второго профиля.
