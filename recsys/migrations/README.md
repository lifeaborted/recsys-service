# Миграции PostgreSQL

Целевая версия стенда — PostgreSQL 17. Первая миграция должна добавить таблицы приложения поверх схемы `recommendations`. История v4 читается из `sales` и `clients`, карточки — из `storefront_catalog` и `historical_item_offers`.

Отдельные миграции понадобятся для сессий, снимков, сигналов и доказательств. `pg_trgm` и `vector` требуются для обогащения каталога. Проверка на синтетике использует отдельную базу. Проверка на v4 использует закрытый экземпляр с существующей выгрузкой.

Миграция `0002_dataset_release.sql` добавляет метаданные релиза. Запись v4 появляется вместе с проверенным дампом. Восстанавливайте его в чистую отдельную БД: дамп уже содержит схему. Запросы из `queries.sql` запускаются вручную.
