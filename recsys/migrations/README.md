# Миграции PostgreSQL

Целевая версия стенда — PostgreSQL 17. Первая миграция должна добавить таблицы приложения поверх схемы `recommendations`. История v3 читается из `sales` и `clients`, карточки — из `storefront_catalog` и `historical_item_offers`.

Отдельные миграции понадобятся для сессий, снимков, сигналов и доказательств. `pg_trgm` и `vector` требуются для обогащения каталога. Проверка на синтетике использует отдельную базу. Проверка на v3 использует закрытый экземпляр с существующей выгрузкой.
