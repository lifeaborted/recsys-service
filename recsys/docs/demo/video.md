## Список кадров для монтажа

1. `/#/demo`, профиль B2B, строка сессии с `request_id`.
2. Карусель: три карточки, подпись про первые три.
3. Модальное окно графа одной карточки, список рёбер.
4. Переключение на `demo-cold (без истории)`, два бейджа: «подтверждено» и «требует проверки».
5. Таблица A/B и строка вариантов.
6. Строка с датой фида и оговоркой про старый каталог.
7. Строка про стоимость из `cost.md`.

## Ограничения

- Не показывать реальные ID клиентов, ночной фид и `sources.json`.
- Не обещать наличие на складе и дату окончания лицензии, если её нет в данных.
- Если на стенде нет нужных карточек, кадр сравнения заменяется честным холодным профилем.
