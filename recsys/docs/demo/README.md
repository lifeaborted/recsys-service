# Интеграция с ЛК (участник 5)

Экран рекомендаций живёт в репозитории ЛК: `E:\github-project\recsys-service\frontend-softline`.
В `recsys` этой зоне принадлежат `api/examples`, `docs/demo` и `tests/e2e/demo`.

## Запуск

```sh
# 1) Синтетические примеры и контракт (без Go-сервера)
cd recsys
node --test tests/e2e/demo/contract.test.mjs

# 2) Фронтенд
cd frontend-softline
npm run dev

# 3) Go API в mock-режиме (по желанию, для проверки HTTP-транспорта)
cd recsys
$env:RECSYS_MOCK='1'   # PowerShell; в sh: RECSYS_MOCK=1
go run ./cmd/api        # http://127.0.0.1:8080/api/v1

# 4) Браузерный тест экрана (Vite должен быть запущен)
cd frontend-softline
npm run test:e2e:demo   # 7 проверок, Chrome/Edge через playwright-core
```

Vite проксирует `/api/v1` на `http://localhost:8080` (переопределяется через
`VITE_PROXY_RECSYS_TARGET`). Адрес API в браузере задаётся `VITE_RECSYS_API_BASE`
(по умолчанию `/api/v1`). По умолчанию включён **mock-транспорт** — публичные данные
берутся из `api/examples`, сервер не нужен.

## Экран

Адрес: **http://localhost:5173/#/demo** (пункт «Рекомендации (демо)» в боковом меню).

На экране:

- «Профиль» — `B2B · demo-b2b` (u1) или `B2C · demo-b2c` (u2);
- «Транспорт» — `mock (синтетика)` или `http (/api/v1)` (Bearer-токен демо-сессии);
- «Сценарий» — авто, полная, частичная, пустая, ошибка, медленный ответ;
- кнопки «Обновить», «Новый run», «Выйти».

## Шаги проверки и ожидаемые надписи

1. **Полная выдача.** Профиль B2B, сценарий «Авто (по профилю)», транспорт mock.
   Ожидается ровно три карточки: «Продление на 12 месяцев», «Апгрейд редакции»,
   «Дополнительный модуль». В строке статуса — `request_id: demo-full-1`, `snapshot: demo-v1`.
2. **Варианты.** В первой карточке нажмите «Сравнить варианты». Ожидаются два
   варианта `DEMO-RENEW-12 · 12 мес.` и `DEMO-RENEW-24 · 24 мес.` с разными
   сроками. У 12‑месячного варианта надпись «Срок окончания неизвестен» — состояние
   неизвестного срока сохраняется.
3. **Причина и граф.** Нажмите «Почему рекомендуем» — показывается только ребро,
   связанное с этой карточкой (`item:DEMO-BASE → item:DEMO-RENEW-12`), с причиной
   и источником `synthetic-rule-1`. Чужые рёбра не раскрываются.
4. **Частичная выдача.** Сценарий «Частичная» (профиль u2 по умолчанию). Баннер:
   `Частичная выдача: insufficient_eligible_products`, одна карточка,
   `request_id: demo-1`.
5. **Пустая выдача.** Сценарий «Пустая» → `Нет рекомендаций для этого профиля.`,
   карточек нет, списки `[]`.
6. **Ошибка.** Сценарий «Ошибка» → `Ошибка model_unavailable (request_id: demo-error-1)`,
   карточек нет.
7. **Медленный ответ и смена профиля.** Сценарий «Медленный ответ», сразу переключите
   профиль на B2C и сценарий «Авто». Старый ответ должен быть проигнорирован: после
   1,5 с остаётся частичная выдача `demo-1` профиля B2C, данные B2B не появляются.
   При выходе данные очищаются (`Сессия не активна`).
8. **HTTP-транспорт.** Переключите «Транспорт» на `http (/api/v1)` при запущенном
   Go API. Тот же экран получает ответ от `GET /api/v1/recommendations/me` с
   заголовком `Authorization: Bearer demo-token-u1/u2`.

## Набор данных

Открытый стенд использует только синтетику `demo-v1`: товары `DEMO-*`, клиенты
`DEMO-BUYER` / `DEMO-NEW` из `testdata/smoke`. Дата актуальности каталога и профилей —
**26.11.2026**, она показана на экране. На питче в рамках хакатона допустимы метрики v4,
граф, рекомендации на псевдо-ID и товары всего фида. На экране отдельно показываются
доли выдачи: другой артикул знакомого семейства, новые продукты, неизвестное семейство.
На экране они подписаны как демонстрационные доли попаданий (в процентах) и посчитаны
по синтетической выдаче; отдельно выведено неизвестное семейство.

Контрольные числа закрытой v4 (из корневого README): 31 753 строки продаж, 19 008
клиентов, 27 603 корзины, 817 товаров (813 с покупками); выборки A — 337 клиентов,
B — 172. Агрегаты качества участника 1 в этом демо **не используются**; если они
появятся, указывайте набор данных явно. Стенд обращается к собственному Go API
(`/api/v1`).

Передача результатов — в [HANDOFF.md](../../tests/e2e/demo/HANDOFF.md).
