# Интеграция с ЛК

Подключение делается в репозитории фронтенда. Пока API не готов, для разработки карточки, графа, сравнения вариантов и частичной выдачи можно использовать [пример JSON](../../api/examples/recommendations.partial.json). [Черновик OpenAPI](../../api/openapi.yaml) задаёт адреса и поля ответа.
